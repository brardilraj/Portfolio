How I work with design teams

The goal is tools designers keep using, so I start with the people, not the technology.

  1. ObserveSit with designers, watch the work and find the real problem behind each complaint.
  2. TestTry AI tools against that problem and keep only what survives real use.
  3. BuildShip a small script, workflow or web utility that designers can open and use the same day.
  4. DocumentWrite short guides so the tool spreads without me in the room.
